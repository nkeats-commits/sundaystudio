Redesign the WorshipFlow app with a polished, modern, warm, pastoral, and professional UI.

The app is for worship pastors, worship leaders, and church creative teams. It should feel like a trusted ministry planning tool, not a generic SaaS dashboard. The design should be beautiful, calm, uncluttered, and easy to use.

Primary design goal:
Make WorshipFlow feel like the “Notion + Planning Center + devotional journal” for worship leaders.

Core tagline:
“Plan worship with depth, not panic.”

DESIGN PERSONALITY

The app should feel:
- Warm
- Pastoral
- Creative
- Trustworthy
- Calm
- Thoughtful
- Premium
- Ministry-minded
- Easy to use

The app should NOT feel:
- Corporate
- Cold
- Overly techy
- Cheesy church stock-photo
- Cluttered
- Overly playful
- Generic AI wrapper

VISUAL STYLE

Use a warm editorial SaaS style.

Think:
- Clean dashboard
- Soft cards
- Warm neutral backgrounds
- Elegant typography
- Thoughtful spacing
- Subtle gradients
- Gentle shadows
- Rounded corners
- Calm icons
- Clear hierarchy
- Beautiful empty states

Suggested inspiration:
- Notion simplicity
- Linear polish
- Planning Center practicality
- The BibleProject warmth
- A modern devotional app
- A premium writing tool

TYPOGRAPHY

Use elegant, readable typography.

Suggested:
- Headings: a refined serif or strong humanist sans-serif
- Body: clean sans-serif

If available, use:
- Headings: Playfair Display, Lora, or Merriweather
- Body: Inter, Source Sans 3, or Manrope

Typography hierarchy:
- Hero headline: large, elegant, confident
- Section headings: clear and warm
- Card titles: semi-bold
- Body copy: readable and calm
- Labels: small, clear, muted

Use generous line height.

LAYOUT PRINCIPLES

Use:
- Lots of breathing room
- Clear sections
- Card-based layouts
- Consistent spacing
- Soft dividers
- Large form fields
- Helpful helper text
- Sticky actions where useful
- Responsive mobile-first design

Avoid dense admin-dashboard clutter.

APP SHELL

Create a beautiful logged-in app shell.

Desktop:
- Left sidebar navigation
- Top header area
- Main content area
- Right-side contextual panel when helpful

Mobile:
- Collapsible menu or bottom navigation

- Output below

- Select dropdowns

“You haven’t saved any services yet. Build your first worship plan and save it here.”

No church profile:

LOADING STATES

Use custom loading messages instead of only generic spinners.

Examples:
- “Preparing your service flow…”
- “Connecting theme, Scripture, and season…”
- “Writing editable liturgy…”
- “Finding songs that fit your congregation…”
- “Creating a devotional for your team…”

ERROR STATES

Errors should be calm and helpful.

Example:
“Something went wrong while generating your content. Try again, or simplify your inputs.”

Do not use scary technical language.

MICROCOPY STYLE

Use warm, pastoral, practical language.

Good:
- “Build a Service”
- “Save to Library”
- “Copy for Planning Center”
- “Generate Another Option”
- “Shape this moment”
- “Add your church context”

Avoid:
- “Submit”
- “Execute”
- “Run AI”
- “Payload”
- “Mutation”
- “System output”

AI OUTPUT DESIGN

Generated content should be displayed in editable document-style blocks.

Each block should have:
- Section title
- Editable content
- Copy button
- Optional regenerate button

For longer outputs, use:
- Sticky table of contents
- Collapsible sections
- Clear headings
- Print-friendly styling

MOBILE DESIGN

Make the app fully responsive.

Mobile priorities:
- Easy form completion
- Large buttons
- Stacked cards
- Minimal sidebar clutter
- Sticky bottom action button for generation
- Output sections collapsed by default where helpful

ACCESSIBILITY

Ensure:
- Strong contrast
- Keyboard navigation
- Focus states
- Labels on inputs
- Buttons have clear text
- Mobile tap targets are large
- Font sizes are readable

FINAL DESIGN REQUIREMENT

The finished design should feel like something worship pastors would actually trust and want to use every week.

It should be beautiful enough to demo, simple enough for a tired worship leader on a Thursday afternoon, and thoughtful enough to feel like it understands ministry.

Prioritize:
1. Clean dashboard experience
2. Beautiful Service Builder
3. Editable document-style AI outputs
4. Warm ministry-focused brand identity
5. Mobile usability
6. Clear navigation
7. Premium but not flashy design

Do not use cheesy church imagery.
Do not use random worship stock photos.
Do not use harsh colors.
Do not make it look like a generic AI chat app.

Make WorshipFlow feel like a calm, intelligent, pastoral workspace for planning worship.
